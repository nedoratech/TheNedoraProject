# NedAI Public Assets

## Required files (not committed — add manually):

- `nedai-logo.png` — NedAI logo (purple/magenta, transparent bg). Source: design team.
- `nedora-logo-white.png` — Nedora wordmark, white version. Copy from `apps/landing/public/svg/nedora-white.png`.
- `fonts/futura-regular.woff2` — Copy from `apps/landing/public/fonts/futura-regular.woff2`.
- `fonts/futura-bold.woff2` — Copy from `apps/landing/public/fonts/futura-bold.woff2`.

## Setup command (run from repo root):
```bash
cp apps/landing/public/svg/nedora-white.png apps/nedai/public/nedora-logo-white.png
cp apps/landing/public/fonts/futura-regular.woff2 apps/nedai/public/fonts/
cp apps/landing/public/fonts/futura-bold.woff2 apps/nedai/public/fonts/
# Then add nedai-logo.png manually
```
