# Futura fonts (licensed — do not commit to public repos)

Place WOFF2 files here. The app references these **exact** filenames:

| File | Weight | CSS usage |
|------|--------|-----------|
| `futura-light.woff2` | 300 | Light (optional) |
| `futura-regular.woff2` | 400 | Body / book |
| `futura-medium.woff2` | 500 | Nav, labels |
| `futura-bold.woff2` | 700 | Headings, CTAs |

If your export uses different names (e.g. `Futura-Book.woff2`), rename or duplicate to match the table above.
